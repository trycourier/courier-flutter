# Courier Flutter SDK

The Courier Flutter SDK provides prebuilt widgets and Dart APIs for adding in-app notifications, push notifications, and notification preferences to your Flutter app. It handles authentication, token management, and real-time message delivery across iOS and Android from a single codebase.

Requires Flutter 3.29+ (Dart 3.7+), iOS 15.0+, Android SDK 23+, and Gradle 8.4+.

## Installation

```bash
flutter pub add courier_flutter
```

### iOS

Flutter sets up the native iOS SDK, [Courier_iOS](https://github.com/trycourier/courier-ios), when it builds.

**Notification service extension:** add Courier_iOS to the extension target with Swift Package Manager. In Xcode, choose **File > Add Package Dependencies**, enter `https://github.com/trycourier/courier-ios`, and pick **Up to Next Major Version**. If the extension has `pod 'Courier_iOS'` in your Podfile, remove it. If Xcode then reports **Cycle inside Runner**, drag **Embed Foundation Extensions** above **Thin Binary** in the Runner target's **Build Phases**.

## Quick Start

```dart
import 'package:courier_flutter/courier_flutter.dart';
import 'package:courier_flutter/ui/inbox/courier_inbox.dart';

// Sign in (JWT generated by your backend)
await Courier.shared.signIn(
    userId: "user_123",
    accessToken: jwt,
);

// Drop in a prebuilt Inbox widget
CourierInbox(
  onMessageClick: (message, _) {
    message.isRead ? message.markAsUnread() : message.markAsRead();
  },
)
```
